## Soal

Tentukan nilai terkecil dari

$$|x-1| + |x-2| + |x-3| + |x-4|$$

untuk $x$ bilangan real.

## Petunjuk

- Empat tanda mutlak, tetapi memecah kasus bukan satu-satunya jalan. Baca lagi sebagai jumlah jarak.
- Pasangkan titik-titiknya dari luar ke dalam: $1$ dengan $4$, lalu $2$ dengan $3$.
- Tiap pasangan mencapai jumlah jarak terkecilnya di ruas di antara keduanya — cari $x$ yang memenuhi kedua pasangan sekaligus.

## Pembahasan

Bentuk itu adalah jumlah jarak $x$ ke empat titik: $1$, $2$, $3$, dan $4$.

**Pasangkan dari luar ke dalam.**

Untuk pasangan terluar, $1$ dan $4$:

$$|x-1| + |x-4| \ \ge\ 4 - 1 = 3$$

dengan kesamaan tepat ketika $1 \le x \le 4$.

Untuk pasangan dalam, $2$ dan $3$:

$$|x-2| + |x-3| \ \ge\ 3 - 2 = 1$$

dengan kesamaan tepat ketika $2 \le x \le 3$.

**Gabungkan.** Jumlah keempatnya paling sedikit $3 + 1 = 4$. Kedua syarat kesamaannya
terpenuhi bersamaan pada

$$2 \le x \le 3$$

yang tidak kosong — jadi batas $4$ benar-benar tercapai.

Nilai terkecilnya adalah $\boxed{4}$.

Periksa di $x = 2$: $1 + 0 + 1 + 2 = 4$. Di $x = 2{,}5$: $1{,}5 + 0{,}5 + 0{,}5 + 1{,}5 = 4$.
Di $x = 1$: $0 + 1 + 2 + 3 = 6$ — memang lebih besar.

**Langkah "kesamaannya tercapai bersamaan" itu wajib.** Menjumlahkan dua batas bawah
selalu memberi batas bawah, tetapi belum tentu batas itu dicapai. Di sini beruntung kedua
ruasnya beririsan; kalau tidak, nilai terkecilnya lebih besar daripada jumlah batasnya.

Hasil umumnya: untuk titik-titik terurut $a_1 \le \cdots \le a_{2m}$, jumlah jaraknya
terkecil di seluruh ruas antara dua titik tengah, dan nilainya jumlah selisih pasangan
dari luar ke dalam. Untuk banyaknya titik ganjil, minimumnya tercapai tepat di titik
tengah.
