## Soal

Buktikan ketaksamaan segitiga: untuk sembarang bilangan real $a$ dan $b$,

$$|a + b| \le |a| + |b|$$

## Petunjuk

- Kedua ruasnya tak negatif, jadi mengkuadratkan aman dan tidak mengubah arah.
- Setelah dikuadratkan, yang tersisa perbandingan antara $ab$ dan $|ab|$.
- Fakta penutupnya: $ab \le |ab|$ untuk sembarang bilangan real.

## Pembahasan

Kedua ruas tak negatif — nilai mutlak tidak pernah negatif, dan jumlah dua bilangan tak
negatif juga tak negatif. Karena itu **mengkuadratkan kedua ruas aman**: untuk
$p, q \ge 0$ berlaku $p \le q \iff p^2 \le q^2$.

Jadi cukup dibuktikan

$$|a+b|^2 \ \le\ \left(|a| + |b|\right)^2$$

**Jabarkan kedua ruas.** Untuk ruas kiri, pakai $|x|^2 = x^2$:

$$|a+b|^2 = (a+b)^2 = a^2 + 2ab + b^2$$

Untuk ruas kanan:

$$\left(|a|+|b|\right)^2 = |a|^2 + 2|a||b| + |b|^2 = a^2 + 2|ab| + b^2$$

sebab $|a||b| = |ab|$.

**Bandingkan.** Kedua ruas hanya berbeda pada suku tengahnya, sehingga yang perlu
dibuktikan tinggal

$$2ab \ \le\ 2|ab| \quad\Longleftrightarrow\quad ab \le |ab|$$

**Buktikan fakta terakhir.** Untuk sembarang bilangan real $t$ berlaku $t \le |t|$:

- Kalau $t \ge 0$, maka $|t| = t$ dan keduanya sama.
- Kalau $t < 0$, maka $|t| = -t > 0 > t$.

Terapkan dengan $t = ab$.

Karena itu $|a+b|^2 \le \left(|a|+|b|\right)^2$, dan karena kedua ruas aslinya tak negatif,
diperoleh

$$|a+b| \le |a| + |b| \qquad \blacksquare$$

**Kapan kesamaannya tercapai?** Dari penurunan di atas, kesamaan berlaku tepat ketika
$ab = |ab|$, yaitu ketika $ab \ge 0$ — yaitu ketika $a$ dan $b$ **bertanda sama** atau
salah satunya nol. Contohnya $|3+5| = 8 = |3|+|5|$, sedangkan $|3 + (-5)| = 2 < 8$.

Namanya berasal dari geometri: pada segitiga, panjang satu sisi tidak pernah melebihi
jumlah dua sisi lainnya. Bentuk yang sering dipakai turunannya juga berguna:

$$\big||a| - |b|\big| \le |a - b|$$

## Rubrik

- Menyatakan kedua ruas tak negatif sehingga mengkuadratkan sah — bukan sekadar mengkuadratkan begitu saja
- Menjabarkan $|a+b|^2 = a^2 + 2ab + b^2$ dengan memakai $|x|^2 = x^2$
- Menjabarkan $\left(|a|+|b|\right)^2 = a^2 + 2|ab| + b^2$, memakai $|a||b| = |ab|$
- Menyusutkan soalnya menjadi $ab \le |ab|$
- Membuktikan $t \le |t|$ lewat dua kasus tanda, bukan menyatakannya begitu saja
- Untuk nilai penuh: menyebut syarat kesamaannya, yaitu $ab \ge 0$
